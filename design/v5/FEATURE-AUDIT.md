# ComWatch — Feature audit vs project docs (2026-06-12)

Source: DOC7 MVP Scope §5–8, DOC6 Governance §8–11, DOC5 Result System.

## ✅ DONE (built in prototype, user-tested & confirmed)
- Core loop: discover → answer → result → insight → next
- All 5 answer modes (Quick Pick, Trade-off, Swipe, Bucket Sort, Tier) + one-screen sorter
- 10 result DV types + animated reveals
- Personal layer (mandatory) + Insight cards/desk notes (mandatory)
- Trending (Heating up rail w/ velocity)
- Categories as filter chips
- Anonymous, no accounts/profiles/notifications (by design)
- Sample visibility (vote counts shown)
- Progressive reveal (vote-to-unlock teaser cards)
- Curated homepage: editorial carousel + sectioned rows (no infinite feed)
- No XP/streaks/comments (per docs, intentional)

## 🟢 EASY KNOCK-OFFS — close in v4
1. Question reactions: Like/Dislike (approved signal, Gov §9)
2. Skip question (Participation scope §7)
3. Question links — per-question URL hash (MVP §5)
4. Related questions on result + Random/"Surprise me" (Discovery §6)
5. Failure/low-data states: placeholder + encouragement (Result §15)
6. Governance status badges: Active / Frozen / Archived (Gov §13)
7. Secondary DV: multi-DV switcher per result (Result §7 + user direction: one question many DVs)
8. Lab winners integration: sorter focus layout, rank animations, podium-slot recolor+motion, liquid waves, gradient heat ramps, real India map (brand inks + lime/fire bubbles), logo formats + 2-3 new questions to host them
